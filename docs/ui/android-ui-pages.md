# acbooks Android 页面设计规范

> 路径：`docs/ui/android-ui-pages.md`<br>
> 上位规范：[android-ui.md](android-ui.md)、[android-reader.md](../architecture/android-reader.md)<br>
> 本文规定页面结构、组件职责与交互。应用控件直接使用 Miuix，样式和动效遵循 Android UI 规范。

当前重建基线提供首页阅读历史空状态、头像设置入口、玻璃搜索浮层，以及书库和统计页面占位。业务布局按以下规范逐步实现，当前可运行内容见 [Android 开发环境](../development/android.md)。

## 1. 主导航与标题

- 默认启动首页，无需登录。三个 Tab：**首页 / 书库 / 统计**（Home / Library / Statistics）。使用 `HorizontalPager` 承载三页，标题跟随 `currentPage`，底栏在正文拖动期间显示已停靠页，松手后跟随目标页。切换保留各页滚动、搜索及布局状态，支持横向滑动，不与内部横向列表手势冲突。系统返回在非首页 Tab 时先回到首页。
- 首页、书库、统计共用 Miuix 玻璃底栏。右侧圆形玻璃搜索按钮打开 `GlassSearchOverlay`。浮层使用玻璃输入栏和取消按钮，退出后回到此前的主 Tab。
- 宽屏使用左侧纵向导航，搜索按钮独立置于上方。根据可用窗口宽度适配横竖屏。
- 首页、书库和统计使用 `GlassTopAppBar` 的可折叠大标题。每个 Tab 使用独立的 `MiuixScrollBehavior`，与本页正文的嵌套滚动联动。顶栏负责状态栏避让，正文根据 `Scaffold` 提供的内边距避开顶底栏。书目计数等辅助信息放在标题下方，有内容时才占位。
- 首页顶栏右上角的设置头像按钮位于 `actions`，点击进入设置。使用 Miuix 图标按钮，有头像时显示服务器同步的图片，否则显示 Miuix 人像图标。可访问名称为「打开设置」。书库和统计顶栏右侧可放各自的页面操作。
- 使用 WindowInsets 和内容留白，确保最后一项可完整显示。阅读器隐藏主导航。
- 设置作为独立页面由首页头像打开。路由转场与浮层动效见 [Android 动画规范](android-motion.md)。
- 设置页使用可折叠 `GlassTopAppBar`，左侧使用玻璃返回按钮。展开和折叠状态都显示当前页名称。

## 2. 首页 Home

```text
                                   [头像/设置]
Good morning

[封面]  继续阅读：书名、作者、进度     [···]

最近阅读
[封面]    [封面]    [封面]    → 横向滚动
 书名      书名      书名
 作者      作者      作者
 进度      进度      进度

今日阅读
        弧形目标进度 / 阅读时长
        每周阅读打卡

[首页   书库   统计]              [搜索]
```

| 区域 | 规范 |
| --- | --- |
| 标题 | 展开的大标题与折叠的小标题均显示同一句问候语，头像位于右上角。中午 12 点切换到 `Good afternoon`，18 点切换到 `Good evening`，午夜切换到 `Good morning` |
| 继续阅读 | 最近实际阅读的一本书；使用 Miuix 卡片，封面宽 72dp、比例 3:4 |
| 卡片背景 | 使用 Miuix 卡片的默认容器色 |
| 最近阅读 | 排除继续阅读书籍，最多 12 本；LazyRow，手机封面宽 96dp、宽屏 120dp，比例 3:4，显示书名、作者和进度 |
| 阅读目标 | 今日有效阅读时长、弧形进度、当周七天打卡；点击打开目标详情/设置 Sheet |
| 页面间距 | 按 Miuix 默认样式分组，宽屏内容最大宽度建议 840dp |

- 点击继续阅读或最近阅读封面打开本地阅读器，返回恢复原滚动位置。更多菜单提供详情、收藏等可用操作。
- 首页只展示已实际阅读的书籍；没有阅读历史时不伪造进度。书库为空时保留标题和主导航。有书但搜索无结果时显示「没有符合条件的书籍」。有书但未读时提供前往书库入口。
- 所有内容来自本地数据；服务器连接、下载状态不阻塞首页。文件不可用时提示重新授权、定位或下载，不丢失阅读历史。
- 第一阶段不增加独立待阅读、推荐流或复杂会员入口。

## 3. 书库 Library

```text
书库

[分类封面]          [书籍封面]          [书籍封面]
 分类名              书名                书名
 数量                作者 / 进度         作者 / 进度
...

[首页   书库   统计]              [搜索]
```

### 3.1 标题与搜索

- 书库主页面使用可折叠大标题和书籍网格。搜索浮层用于匹配书名与作者，支持清除和修改查询。

### 3.2 书籍展示

| 模式 | 布局 |
| --- | --- |
| 标准网格 | 手机 2 列；横向间距 24dp |
| 紧凑网格（默认） | 手机 3 列；横向间距 12dp |
| 列表 | 左封面、右书名/作者/进度/状态；高度随文字增长 |
| 宽屏 | 自适应列宽，网格最小 140dp |

- 封面比例 3:4，书名最多两行，作者置于书名下方。文字使用 Miuix 字阶。无封面使用统一占位图与书名。
- 封面是视觉中心。收藏、阅读进度、待下载、文件缺失等状态使用小图标或简短文字。
- 分类在普通书籍前展示，使用同尺寸组合封面、名称和数量；文件夹内可保留返回路径。
- 点击可用封面进入阅读器，点击封面下方的书名进入书籍详情。未下载的书籍先显示下载操作。
- 规划中的编辑模式提供完成、删除、标签、移动等批量操作，并提供已选数量和全选；退出恢复正常工具栏。移除书目与删除文件必须分开确认，授权目录原文件默认不删除。
- 布局与排序偏好持久化；第一阶段不实现 Cover Flow 和书脊模式，不预留无效入口。

- 书库支持本地 EPUB/PDF 网格及书名和作者搜索。在书籍详情中可将书籍加入或移出现有书架。从阅读器或详情返回时保留网格和搜索状态。

## 4. 主导航搜索与导入能力

主导航的独立搜索按钮使用 Miuix 中性玻璃材质和随浅色、深色切换的图标色。导入入口按以下规则实现。

- 本地文件：系统文件选择器、多选、默认复制到 App 私有存储。
- 授权文件夹：SAF 持久读取权限 → 递归扫描 → 多选/全选 → 批量导入；默认引用原文件，支持主动复制；可刷新与重新授权。
- 服务器导入：通过现有账号及 API 进入远程书库、选择和下载；不直接访问服务器文件系统。
- 导入支持取消、重复检测、进度和错误反馈；在书库分类内发起时允许选择当前虚拟分类，不擅自移动原文件。返回后保留当前 Tab。

## 5. 其他页面基线

| 页面 | 结构 |
| --- | --- |
| 统计 | 可折叠大标题；时长、次数、间隔；趋势、月度热力日历、时间线；点击日期查看各书时长与记录 |
| 书籍详情 | 封面、书名/作者、继续阅读、书目信息、文件、阅读记录、笔记/书签；宽屏可双栏 |
| 阅读器 | 沉浸式正文，隐藏状态栏/导航栏且不显示顶栏；PDF 底部保留上一页、页码和下一页。翻页控件及目录、进度、笔记、书签与阅读设置浮层直接使用 Miuix。正文纸色独立 |
| 设置 | 首页头像进入设置目录。顶部头像卡片只显示头像和昵称，点击 56dp 头像打开照片选择器并上传/本地保存；不显示说明、箭头或昵称编辑入口。头像卡与下方分组使用官方 `glassPanel`，多行入口共用一个分组并使用 `ArrowPreference`。外观页使用 `GlassDropdownPreference` 设置主题和语言 |
| 服务与服务器登录 | 设置 → 服务 → acbooks 服务器。设置目录、外观、服务、服务器与登录共用玻璃顶栏与分层背景采样。服务器状态页从上到下为连接状态卡、操作和说明卡。未配置时，状态卡居中显示「未连接」和「未配置」，全宽 Miuix 按钮「配置服务器」打开独立登录页 |

登录页的「服务器」字段接受 HTTPS 地址，可先测试连通性，再用 `GlassTextField` 填写账号和密码，通过主题色按钮登录。登录成功后返回连接状态页。已登录时，状态卡下方提供测试连接和退出登录，分别用于验证和撤销设备会话。

打开图书时从点按的封面或列表项展开，返回时收回同一个来源位置。首页的继续阅读和书库内的同一本书可以有不同来源。来源不可用时采用普通导航转场。

## 6. 组件与实现约束

- 通用导航、按钮、搜索和菜单直接使用 Miuix。继续阅读、最近阅读、封面、网格项和列表项可作为书籍业务组件跨页面复用。
- 首页和书库各自持有 ViewModel，通过 Repository 读取本地数据；不在 UI 执行文件扫描或同步。所有文本同时提供中英资源；放大字体时允许布局换行，不压缩触控区。
- 验收：未登录能搜索和阅读本地书籍；切换 Tab 保留状态；小屏、横屏、平板和深色模式均可用，阅读器和浮层保留原有操作。滑动和阅读过渡必须真机验证。
