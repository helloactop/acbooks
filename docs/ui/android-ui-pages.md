# acbooks Android 页面设计规范

> 路径：`docs/ui/android-ui-pages.md`<br>
> 上位规范：[android-ui.md](android-ui.md)、[android-reader.md](../architecture/android-reader.md)<br>
> 本文规定页面结构、组件职责与交互。应用控件直接使用 Miuix，样式和动效遵循 Android UI 规范。

## 1. 主导航与标题

- 默认启动首页，无需登录。三个 Tab：**首页 / 书库 / 统计**（Home / Library / Statistics）。使用 `HorizontalPager` 承载三页，底栏选中项跟随 `currentPage`；切换保留各页滚动、筛选及布局状态，支持横向滑动，不与内部横向列表手势冲突。系统返回在非首页 Tab 时先回到首页。
- 手机使用 Miuix 底部导航，添加按钮单独放在右侧。点击添加时保留当前 Tab 的选中状态。
- 宽屏使用左侧纵向导航，添加按钮独立置于上方。根据可用窗口宽度适配横竖屏。
- 首页、书库、统计三页复用 `MainTabHeader`。使用 Miuix 大标题顶栏，标题随系统字体和标题换行扩展。日期、书目计数等辅助信息放在标题下方，有内容时才占位。
- 首页右上角与大标题同排显示设置头像按钮，点击进入设置。使用 Miuix 图标按钮，有头像时显示服务器同步的图片，否则显示 Miuix 人像图标。可访问名称为「打开设置」。书库和统计共用标题位置，右侧可放各自的页面操作。
- 使用 WindowInsets 和内容留白，确保最后一项可完整显示。阅读器隐藏主导航。
- 设置作为独立页面由首页头像打开。路由转场与浮层动效见 [Android 动画规范](android-motion.md)。
- 设置等二级页面直接使用 Miuix 顶栏，左侧提供返回操作，页面名称居中。

## 2. 首页 Home

```text
首页                              [头像/设置]
日期 / 星期

[封面]  继续阅读：书名、作者、进度     [···]

最近阅读
[封面]    [封面]    [封面]    → 横向滚动
 书名      书名      书名
 作者      作者      作者
 进度      进度      进度

今日阅读
        弧形目标进度 / 阅读时长
        每周阅读打卡

[首页   书库   统计]                [+]
```

| 区域 | 规范 |
| --- | --- |
| 标题 | 左上角大标题，右上角头像进入设置；日期和星期在标题下方 |
| 继续阅读 | 最近实际阅读的一本书；使用 Miuix 卡片，封面宽 72dp、比例 3:4 |
| 卡片背景 | 使用 Miuix 卡片的默认容器色 |
| 最近阅读 | 排除继续阅读书籍，最多 12 本；LazyRow，手机封面宽 96dp、宽屏 120dp，比例 3:4，显示书名、作者和进度 |
| 阅读目标 | 今日有效阅读时长、弧形进度、当周七天打卡；点击打开目标详情/设置 Sheet |
| 页面间距 | 按 Miuix 默认样式分组，宽屏内容最大宽度建议 840dp |

- 点击继续阅读或最近阅读封面打开本地阅读器，返回恢复原滚动位置。更多菜单提供详情、收藏等可用操作。
- 首页只展示已实际阅读的书籍；没有阅读历史时不伪造进度。书库为空时不显示额外空态，只保留标题、搜索/筛选行和独立添加入口；有书但筛选无结果时显示「没有符合条件的书籍」。有书但未读时提供前往书库入口。
- 所有内容来自本地数据；服务器连接、下载状态不阻塞首页。文件不可用时提示重新授权、定位或下载，不丢失阅读历史。
- 第一阶段不增加独立待阅读、推荐流或复杂会员入口。

## 3. 书库 Library

```text
书库                             [编辑] [···]
[ 搜索书籍                 ]   [全部⌄ │ 分类]

[分类封面]          [书籍封面]          [书籍封面]
 分类名              书名                书名
 数量                作者 / 进度         作者 / 进度
...

[首页   书库   统计]                [+]
```

### 3.1 标题与筛选

- 书库顶部直接显示大标题，省去藏书和已读数量副标题。标题右侧的编辑和更多操作使用 Miuix 图标按钮；进入分类时显示名称和返回路径。
- 搜索、快捷筛选和分类入口直接使用相应的 Miuix 控件。左侧搜索占剩余宽度，右侧放快捷筛选和分类入口。
- 搜索入口打开独立搜索浮层，聚焦键盘，实时匹配书名、作者、标签；支持清除、退出、空结果；关闭保留原书库状态。
- 快捷筛选：全部、EPUB、PDF、收藏、阅读状态、标签；仅展示已实现的格式与可用标签。菜单锚定触发区域，显示当前选中项。
- 分类入口浏览虚拟分类、标签、已授权文件夹；虚拟分类和物理目录分离，不把分类移动等同于物理文件移动。服务器书库是独立入口，不混入本地目录授权。
- 更多菜单集中排序（最近阅读、添加时间、书名、作者）、布局、创建分类、刷新授权目录、手动同步（连接后可用）；不堆叠常驻工具按钮。

### 3.2 书籍展示

| 模式 | 布局 |
| --- | --- |
| 标准网格 | 手机 2 列；横向间距 24dp |
| 紧凑网格（默认） | 手机 3 列；横向间距 12dp |
| 列表 | 左封面、右书名/作者/进度/状态；高度随文字增长 |
| 宽屏 | 自适应列宽，网格最小 140dp |

- 封面比例 3:4，书名最多两行，作者置于书名下方。文字使用 Miuix 字阶。无封面使用统一占位图与书名。
- 封面是视觉中心。收藏、阅读进度、待下载、文件缺失等状态使用小图标或简短文字。
- 分类在普通书籍前展示，使用同尺寸组合封面、名称和数量；文件夹内可保留返回路径。
- 点击可用封面进入阅读器，点击封面下方的书名进入书籍详情。未下载的书籍先显示下载操作。
- 编辑模式将搜索筛选行替换为完成、删除、标签、移动等批量操作，并提供已选数量和全选；退出恢复正常工具栏。移除书目与删除文件必须分开确认，授权目录原文件默认不删除。
- 布局与排序偏好持久化；第一阶段不实现 Cover Flow 和书脊模式，不预留无效入口。

当前 Android 页已支持本地 EPUB/PDF 网格、书名和作者搜索、格式与书架筛选、按添加时间或书名排序。书架可创建和删除，在书籍详情中可同时加入或移出多个书架。删除书架保留书籍和正文。从阅读器或详情返回保留书库与筛选状态。

## 4. 独立添加按钮

- `+` 打开 Miuix 底部浮层，提供本地文件导入、进度、停止导入及结果。不需要登录。授权本地文件夹与从 acbooks 导入在对应能力接通后提供。
- 本地文件：系统文件选择器、多选、默认复制到 App 私有存储。
- 授权文件夹：SAF 持久读取权限 → 递归扫描 → 多选/全选 → 批量导入；默认引用原文件，支持主动复制；可刷新与重新授权。
- 服务器导入：通过现有账号及 API 进入远程书库、选择和下载；不直接访问服务器文件系统。
- 导入支持取消、重复检测、进度和错误反馈；在书库分类内发起时允许选择当前虚拟分类，不擅自移动原文件。返回后保留当前 Tab。

## 5. 其他页面基线

| 页面 | 结构 |
| --- | --- |
| 统计 | 共用大标题；时长、次数、间隔；趋势、月度热力日历、时间线；点击日期查看各书时长与记录 |
| 书籍详情 | 封面、书名/作者、继续阅读、书目信息、文件、阅读记录、笔记/书签；宽屏可双栏 |
| 阅读器 | 沉浸式正文，隐藏状态栏/导航栏且不显示顶栏；PDF 底部保留上一页、页码和下一页。翻页控件及目录、进度、笔记、书签与阅读设置浮层直接使用 Miuix。正文纸色独立 |
| 设置 | 首页头像进入设置目录。顶部头像卡片只显示头像和昵称，点击 56dp 头像打开照片选择器并上传/本地保存；不显示说明、箭头或昵称编辑入口。头像卡与下方入口共用 Miuix `Card`：多行入口合并在同一张卡内，使用 `ArrowPreference`，卡片圆角、行内边距与无分隔线行为沿用 Miuix 默认。外观详情使用 Miuix `OverlayDropdownPreference` 选择跟随系统、浅色或深色 |
| 服务与服务器登录 | 设置 → 服务 → acbooks 服务器。设置目录、外观、服务、服务器与登录直接使用 Miuix 页面容器及卡片。沿用居中顶栏，正文从上到下为连接状态卡、操作和说明卡。未配置时，状态卡居中显示「未连接」和「未配置」，全宽 Miuix 按钮「配置服务器」打开独立登录页 |

登录页的「服务器」字段接受 HTTPS 地址，可先测试连通性，再填写账号和密码，通过主题色按钮登录。登录成功后返回连接状态页。已登录时，状态卡下方提供测试连接和退出登录，分别用于验证和撤销设备会话。

打开图书时从点按的封面或列表项展开，返回时收回同一个来源位置。首页的继续阅读和书库内的同一本书可以有不同来源。来源不可用时采用普通导航转场。

## 6. 组件与实现约束

- 通用导航、按钮、搜索和菜单直接使用 Miuix。继续阅读、最近阅读、封面、网格项和列表项可作为书籍业务组件跨页面复用。
- 首页和书库各自持有 ViewModel，通过 Repository 读取本地数据；不在 UI 执行文件扫描或同步。所有文本同时提供中英资源；放大字体时允许布局换行，不压缩触控区。
- 验收：未登录能完成导入和阅读；切换 Tab 保留状态；长按、批量编辑、搜索和筛选无冲突；小屏、横屏、平板和深色模式均可用，阅读器和浮层保留原有操作。滑动和阅读过渡必须真机验证。
