## 1. 一句话原则

1. **内容第一**：书、封面、书名、状态是主角；装饰、阴影、渐变都不能比内容更显眼。
2. **一个区域一个主操作**：同一块操作区只有一个视觉最强的按钮。
3. **看得见当前状态**：控件显示"现在是什么"，不让用户点开才知道。
4. **同类信息放一处**：筛选、操作、状态各有固定位置，不分散。
5. **没做的功能不露面**：不放灰按钮、占位标签或假入口，不伪造数据和成功提示。
6. **两种语言一样好用**：中英文共用同一布局，不靠缩字号解决溢出。

## 2. 全局约束

- **R-G-1 技术栈**：React + TypeScript strict + Vite + Tailwind CSS + shadcn/ui + Radix Primitives + Lucide React。Radix Colors 用于默认色阶；自定义配色时可评估 Culori。**禁止**引入 Mantine、Radix Themes、DaisyUI 等完整 UI 体系；新增依赖先核对 GPL-3.0-only 兼容性。
- **R-G-2 禁止的视觉**：毛玻璃、液态玻璃、背景模糊、折射、渐变装饰、普通卡片阴影（浮层可用轻微阴影）。横向滚动边缘的功能性渐隐是唯一渐变例外：只提示溢出，使用当前背景语义令牌，不遮住必要信息，并同时提供箭头。
- **R-G-3 令牌**：组件只用 CSS 语义令牌，**禁止**硬编码色值或直接引用调色板。shadcn/ui 默认变量映射到同一套令牌，不产生第二套主题。唯一例外是占位封面调色板（`library/presentation.ts`）。
- **R-G-4 图标**：见第 5 节。
- **R-G-5 动效**：默认 `150ms ease-out` 颜色过渡；主题 180ms、弹窗 200ms、侧栏 220ms、抽屉 240ms。禁止 hover 缩放、弹跳和全局 `transition-all`；尊重 `prefers-reduced-motion`，保留必要的状态反馈。
- **R-G-6 状态**：任何列表、详情、表单都覆盖加载、空、错误（可重试）、成功、禁用；异步任务展示服务端实际状态，不把"受理"当成功；刷新时保留已有内容并标明更新中，不把未知数据当 0。
- **R-G-7 参考**：借鉴 Readest 的克制、Lumi 的圆角、Radix 的色阶、Mantine 的按钮、Tome 的布局、Stump 的组件组织；只借机制，不复制实现。

## 3. 主题与颜色

- **R-C-1** 外观模式：跟随系统（默认）/ 浅色 / 深色。**唯一内置配色为淡蓝**，种子色 `#5D92E8`（它不等于可读的强调文字色）。保留自定义主题能力：用户可改背景、文字、强调色，派生色统一生成并验证对比度。
- **R-C-2** 模式与配色独立，书库与阅读器主题独立。偏好保存在本地，不持久化认证凭据；首屏不闪烁，系统模式响应系统变化；不新增后端主题接口或数据表。
- **R-C-3** 以根节点主题属性和 `color-scheme` 统一切换，弹窗、菜单等 Portal 同步继承。

## 4. 尺寸与排版

以下为 Web CSS px 基准，实现优先使用可缩放的 rem 令牌。Android 用对应 dp/sp。

| 项目 | 规范 |
| --- | --- |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 |
| 圆角 | 标签/复选框 4；封面 8；按钮/输入框 10；菜单 12；卡片 14；大卡片 18；主面板 22；弹窗 24；胶囊 full |
| 字号 | 页标题 22/600；区块 16–18/600；正文 14；操作 13；辅助 12；**最小可读文字 11**；移动端正文 16 |
| 控件高度 | 小 28；标准 32；大 40；登录输入框 44；**移动端触控目标 ≥ 44×44** |
| 图标 | 普通 16–18；导航 20；辅助 14；空状态 32–48；`strokeWidth=2` |
| 内容 | 页面边距 16–20；区块间距 16；顶栏 56；表格行 48（紧凑 40）；设置行最小 56 |
| 字体 | 系统字体；正文行高 1.5；统计数字等宽数字；阅读排版独立 |

- **R-T-1** 同心圆角：内圆角 = `max(0, 外圆角 − 内缩距离)`，仅用于同心轮廓。主面板 22、内缩 8，内部卡片用 14。
- **R-T-2** 一条细栏（批量操作条、工具条）用卡片圆角 14，**不用**主面板圆角 22。
- **R-T-3** 不要把普通卡片和输入框全部做成胶囊。
- **R-T-4** 可读文字**必须** ≥ 11px，占位封面文字也一样。32px 列表缩略封面无法容纳文字时只显示简洁占位图形，书名与作者由旁边正文提供；不得缩成不可读小字。

## 5. 图标

- **R-ICON-1** Web / Windows 统一使用 `lucide-react`（已在 `packages/acbooks-ui/package.json`）；Android 使用同语义的 Lucide 资源。**禁止**混用其他图标库、Emoji、Unicode 符号和手绘 SVG。图标本地打包、按需具名导入，禁止 CDN。
- **R-ICON-2** 线性、圆端点，`strokeWidth=2`、`fill=none`、`currentColor`。普通 18、导航 20、辅助 16、面包屑分隔 12–16、空状态 32–48；`Button` / `IconButton` 内子图标默认 18、不收缩，图文间距 8。图标大小不等于点击区域。
- **R-ICON-3** 颜色继承语义文字令牌：普通 `foreground`、次要 `muted-foreground`、强调 `accent-text`、危险 `destructive-text`；危险确认随按钮前景。不为普通图标画实心强调色底板。
- **R-ICON-4** **文字已表达含义时不加图标**。图标用于纯图标按钮，或文字不足以快速辨识且确有扫视收益的操作；同一操作区保持一致。
- **R-ICON-5** 有可见文字的图标 `aria-hidden="true"`；纯图标控件由控件提供本地化 `aria-label`，必要时 Tooltip；图标本身不获得焦点，不单独承担点击（用真正的 Button/链接）。快捷键中的 `⌘` 等字符属于文本提示，不属于功能图标，不受 R-ICON-1 的符号禁令限制。
- **R-ICON-6** 品牌 Logo、Favicon、安装图标不属于功能图标库，沿用 `apps/acbooks-web/public/` 资源，不替换、不随主题染色。

## 6. 组件

### 6.1 通用

- **R-COMP-1** 共享组件放 `packages/acbooks-ui/`，业务页面放各应用；优先复用，按真实需求实现，不预建空模块。
- **R-COMP-2** 公共组件只接收类型化 props、状态和回调，**不请求业务 API、不持有业务权限逻辑**；保留原生元素语义、键盘操作和 ref 传递；**禁止嵌套交互元素**（如 button 内再放 button）。
- **R-COMP-3** **禁止**通过页面 `className` 覆盖公共组件的核心颜色、尺寸和圆角；需要新变体先检查本规范。`className` 可用于外层布局、宽度和对齐；组件明确提供的尺寸或变体 props 是修改核心外观的入口。
- **R-COMP-4** 国际化：组件文案来自共享翻译资源或调用方传入的已本地化 props；内置默认文案（Spinner、PasswordInput、关闭、分页）随语言更新；不在组件内建独立语言状态。
- **R-COMP-5** 中英文共用组件：按钮宽度由内容决定，长文案允许重排；设置行、菜单、表格标题、Dialog footer 允许换行；不裁切重要操作名称，不缩小字号或命中区。

### 6.2 按钮

| 变体 | 外观 | 用途 |
| --- | --- | --- |
| `soft` | `accent-soft` 底 + `accent-border` 1px 边框 + `accent-text` + 600 字重；Hover/Active 用 `accent-hover` / `accent-active`（仍为淡色） | 每个操作区**唯一**主操作（添加、导入、登录、阅读） |
| `default` | `surface` 底 + `foreground` | 表单提交、确认、应用（保存、确认） |
| `outline` | 透明底 + `control-border` | 次要、可逆、导航或筛选操作 |
| `ghost` | 透明无边框 | 取消、编辑、工具栏、分页数字 |
| `danger` | 透明底 + `destructive-text`，Hover 极淡危险色背景 | **删除入口**（打开确认框的按钮） |
| `danger-confirm` | `destructive` + `destructive-foreground` | **仅限**对话框里的最终确认 |

- **R-BTN-1** 同一操作区最多一个 `soft`；不混用多个 `default`；不把 `outline` 当主操作。不提供普通 `solid` 变体。
- **R-BTN-2** 普通按钮禁止黑色、白色反相或高饱和实心填充；只有危险最终确认允许红色实心。
- **R-BTN-3** 打开确认框的入口按钮用 `danger`，**不用** `danger-confirm`。
- **R-BTN-4** 同组按钮统一高度、间距和对齐；空间不足时整组响应式换行，不出现孤立按钮或重复操作。
- **R-BTN-5** 尺寸 `sm / md / lg` = 28 / 32 / 40 高，横向内边距 10 / 12 / 16，圆角 10，文字 13/500（Soft 13/600）；边框预置 1px，避免状态变化引起布局位移。移动端命中区 ≥ 44×44。
- **R-BTN-6** 禁用态用 `disabled-*` 令牌，不降整体透明度；`loading` 保留原宽高、显示 Spinner 并阻止重复触发，并有可访问状态提示；焦点环用 `ring`；不做 Hover/Active 缩放或位移。普通按钮默认 `type="button"`，表单提交显式 `submit`。
- **R-BTN-7** 分页的当前页用中性样式（如 `outline`）加 `aria-current="page"`，**不用** `soft`，避免与页面主操作争夺。
- `IconButton`：默认 `ghost`、32×32、图标 16–18；必须有可访问名称，移动端扩大命中区至 44×44。

### 6.3 表单控件

| 组件 | 规范 |
| --- | --- |
| `Field` | Label → Control → Description/Error，间距 8；label 关联控件；错误与说明用 aria 关联；必填有文字或语义提示 |
| `Input` / `PasswordInput` | 高 32（认证 44，移动 44）、圆角 10、内边距 10；始终保留 `control-border`；密码可见切换用 IconButton 且不丢失焦点；支持 autofill；错误用危险边框和文字；禁用态保持边框与尺寸 |
| `Textarea` | 圆角 10、最小高 96；可纵向扩展，不固定裁切 |
| `Select` / `Combobox` | `Select` 触发器高 32（移动 44）、圆角 10、末尾箭头、选中项带勾；选项多、需搜索用 `Combobox`；浮层位于打开的 `dialog` 内时挂载到该 dialog，否则挂载到 body；支持分组、方向键/Home/End/Enter/Escape、点击外部关闭；不用原生列表 |
| `Checkbox` / `Radio` | 视觉 18×18；Checkbox 圆角 4、Radio 全圆；标签可点击；批量选择支持 indeterminate |
| `Switch` | 轨道 40×24 胶囊；仅用于即时布尔设置；用位置和语义表达状态，不只靠颜色 |
| `SearchInput` | 高 32（移动 44）；图标 + 输入 + 清除；清除不改变布局；输入法组合结束后才触发搜索 |
| `MultiValueInput` | 最小高 32（移动 44）；值标签 24，移除按钮移动端 44×44 并带"移除"可访问名称；直接维护数组；回车/逗号添加，退格删除末项；失焦提交草稿；输入法组合期间不提交 |

- **R-FORM-1** 输入框必须有可辨认边界，不能只用浅灰背景，也不得在页面样式里移除边框。
- **R-FORM-2** 校验失败显示字段错误或表单级错误；保留非敏感输入；**不把密码、初始化码、认证令牌写入本地持久化或日志**。

### 6.4 选择控件的使用

- **R-SEL-1** 默认情况下，**二到四个简短互斥选项**用分段控件（`SegmentedControl`）：外观模式、语言、网格/列表、阅读状态、统计周期。
- **R-SEL-2** **五个以上**或选项很长用下拉。明确例外：书库的状态筛选和排序、书籍编辑表单中的阅读状态可用带可见标签的 `Select`，保证工具栏与表单紧凑；详情头部阅读状态、设置中的模式/语言、网格/列表切换仍用分段控件。
- **R-SEL-3** 下拉框必须让用户看到它管什么：触发器显示"标签：当前值"（如"排序：最近添加"），或旁边有可见标签。**禁止**只显示"全部""最近"这类无上下文的值。
- **R-SEL-4** 分段控件：中性胶囊轨道、高 32（移动 44）、内边距 2；选中块为中性色并带 `segment-selected-border` 边框，内外同心圆角；选项等高；有选中语义和键盘操作；**不用主题色实心选中**；切换时容器尺寸稳定。
- `Tabs`：高 32（移动 44）、文字 13，底部指示线或中性样式；不用整行实心强调色；仅真正的 tab panel 使用 Tabs 语义。

### 6.5 菜单（⋯）

- **R-MENU-1** ⋯ 菜单放低频操作；通常**至少两项**才用菜单，只有一项时直接放成按钮。详情页整书操作是明确例外（R-DETAIL-3）：即使只有删除，也收入 ⋯ 菜单，不为凑数新增功能。
- **R-MENU-2** 危险操作放在菜单底部，用 `danger` 样式，前面加分隔线。
- **R-MENU-3** 菜单内有多类选项时用分组标题和分隔线，不平铺混排。
- 菜单：圆角 12、内边距 4、项最小高 32（移动 44）、图标 16；Portal 浮层，视口碰撞翻转和滚动重定位；打开后聚焦首项，Esc/选择恢复触发源焦点，Tab 关闭并继续到下一控件；在原生 dialog 内挂载到该 dialog。

### 6.6 浮层与确认

| 组件 | 规范 |
| --- | --- |
| `Dialog` | 圆角 24；内边距 20（移动 16）；普通最大宽 480，编辑表单可达 640；Header / Body / Footer；Body 独立滚动，Footer 固定；取消 `ghost`，确认 `default` 或 `soft` |
| `AlertDialog` | 复用 Dialog；清楚显示目标和后果；危险操作用 `danger-confirm`；默认焦点在安全操作；失败保留对话框，不假报成功 |
| `Popover` | 圆角 12、内边距 12–16；适合短筛选/轻量编辑，大表单用 Dialog；不被卡片裁切 |
| `Drawer` | 移动导航/窄屏面板；内边距 16、贴边；支持关闭、滚动和安全区；不用玻璃或模糊 |
| `Tooltip` | 小型实色浮层、圆角 12；说明图标操作；鼠标与焦点都可访问；不承载必要信息或交互按钮 |

- **R-OVL-1** 新浮层优先复用已有 Radix 封装处理 Portal、焦点陷阱（模态）、Esc、键盘导航与焦点恢复；已有原生 `dialog` 实现若满足相同键盘、背景隔离、焦点恢复及嵌套浮层要求并经验证，可继续使用，不为统一底层库重写；浮层继承当前主题；遮罩只用普通半透明暗层，不模糊。
- **R-OVL-2** Dialog/Drawer 不超出可用视口；窄屏保留安全边距和可操作的 footer；提交中不能重复触发；关闭不会自动取消已提交的服务端任务；危险操作不得仅靠颜色表达风险。
- **R-OVL-3** 有未保存修改时，关闭（按钮、取消、Esc、遮罩）先确认"放弃修改 / 继续编辑"。

## 7. 应用框架与导航

### 7.1 AppShell

- **R-L-1** 宽屏布局（视口宽 ≥ 768px **且高 ≥ 480px**）：**80px 图标轨 + 56px 顶栏**；主内容是四周留 8px、浮在 `frame` 之上的圆角面板（22px，`background`），所有断点一致；图标轨、顶栏与内容之间不画分割线。
- **R-L-2** 紧凑布局（视口宽 < 768px **或高 < 480px**）：左侧抽屉；标题行内有菜单触发，由 `PageHeader` 渲染，只在紧凑布局出现。
- **R-L-3** 主内容是唯一主要纵向滚动容器；图标轨和顶栏不随内容滚动；弹窗内部滚动属于例外；隐藏可视滚动条但保留滚轮、触控和键盘滚动（见 R-A11Y-3）。不锁定浏览器缩放。
- **R-L-4** 外壳：`height:100dvh`，flex；框架用 `frame`，主内容用 `background`；移动端内边距 8（视觉外边距 16），≥ 768px 水平 20；区块间距 16。
- **R-L-5** 登录、初始化、沉浸阅读、开发预览不使用管理框架；业务页面不自行创建第二套框架。
- **R-L-6** 唯一宽屏判定是 `(min-width: 768px) and (min-height: 480px)`；其余均为紧凑布局。不识别设备型号或只依赖横竖屏。AppShell、顶栏、图标轨、菜单触发、搜索实例和抽屉历史清理必须复用该条件。844×390 使用抽屉，768×1024 使用图标轨；低高度桌面窗口同样使用抽屉。`100dvh` 只约束外壳，主内容与抽屉内部保持可滚动，不设置内容固定高度。

| 视口条件（先判断高度） | 导航 | 书库控件 |
| --- | --- | --- |
| 高 < 480（任意宽） | 抽屉 | 按可用宽度换行，保留 44px 命中区 |
| 宽 ≥ 1024 且高 ≥ 480 | 图标轨 + 顶栏 | 分段与控件单行；长英文或缩放时可换行 |
| 宽 768–1023 且高 ≥ 480 | 图标轨 + 顶栏 | 类型分段单独一行，状态/排序与工具栏一行 |
| 480–767 | 抽屉 | 类型分段整行；状态/排序各占一半；筛选/视图/更多右对齐成组 |
| < 480 | 抽屉 | 网格 1–2 列，控件仍整齐分组 |

### 7.2 图标轨与导航

- **R-NAV-1** 只列**已实现**的一级入口，不摆放禁用占位。
- **R-NAV-2** 分两组：上组**内容**（首页、**书库**），下组**管理**（存放位置、存储与扫描），两组之间用细分隔线或间距分开。
- **R-NAV-3** 图标 20 + 名称 **11–12px**；80px 宽下中英文都不得被截断（超长时缩短文案，不缩字号）。项宽约 64–72、圆角 10。选中：`accent-soft` + `accent-text` + `aria-current="page"`，同时改变图标与文字颜色。悬停、选中、焦点要有区分。
- **R-NAV-4** 命名统一：产品名 **acbooks**（品牌名，不翻译）；书库页全站叫"**书库**"（侧栏、页面标题、浏览器标题、词条一致），**不再**使用"图书库"、"图书馆"。
- **R-NAV-5** 实体书/电子书不是一级导航，是书库页内的分段筛选（全部书籍 / 实体书 / 电子书）。`mediaType=physical/digital` 表示存在相应副本/文件；未绑定资源的书目仍出现在"全部书籍"，不擅自判为实体书。
- **R-NAV-6** 动态书架以稳定 ID 作 key 和路由参数；需真实书架列表 API 后才启用，不用名称自造 UUID。未实现的阅读、书架、统计等入口不显示。
- **R-NAV-7** 导航配置在图标轨和抽屉共用（`layout/navigation.ts`）。长用户名在顶栏截断并保留完整可访问名称。

### 7.3 顶栏与账户入口

- **R-TOP-1** 左侧全局搜索（最宽 420px，高 32，< lg 为 44）；快捷键提示：macOS 显示 `⌘K`，其他显示 `Ctrl K`。
- **R-TOP-2** 右侧账户入口（头像 + 昵称），点击**直接进入设置页**，不展开菜单；不设独立的设置或退出按钮。退出登录放在设置页账户分组。
- 页面标题不在顶栏，由各页 `PageHeader` 负责。

### 7.4 移动抽屉

- **R-DRAWER-1** 从左侧滑入，宽 `min(82vw, 280px)`；遮罩用普通半透明令牌；时长 240ms，尊重减弱动态，只对 transform/opacity 做动画。
- **R-DRAWER-2** 内容依次：品牌与关闭、全局搜索、一级导航（首页、书库、位置、存储）、底部账户入口（头像 + 昵称，点击进入设置）。与桌面共用同一导航配置。
- **R-DRAWER-3** 手势：从屏幕左缘（约 28px 内）向右滑打开，抽屉内向左滑关闭；水平位移 ≥ 56px 且明显大于垂直位移；垂直滚动、表单输入区域、页面内横向滚动区域上的滑动不触发。
- **R-DRAWER-4** 点击菜单项关闭并导航；点击遮罩、关闭按钮、Esc、浏览器返回键都能关闭。打开时锁定背景滚动，背景不可聚焦，焦点进入抽屉并循环，关闭后回到触发按钮。
- **R-DRAWER-5** 抽屉用 React Router 管理的**同址历史条目**（`acbooksDrawer` 状态）；抽屉内导航以 replace 复用该条目，不残留重复历史；进入 R-L-6 定义的宽屏布局时立即清理抽屉状态；关闭状态不得存在可点击的透明覆盖层。
- 低高度视口：抽屉顶部/底部固定，中部滚动。适配 `env(safe-area-inset-*)`、地址栏和软键盘。

### 7.5 全局搜索

- **R-SEARCH-1** 只用于查询整个书库；书库页内**不放第二个搜索框**。桌面在顶栏，移动在抽屉顶部；同一时刻只有一个搜索实例。
- **R-SEARCH-2** `Ctrl/⌘+K`：桌面聚焦顶栏搜索；移动端先打开抽屉再聚焦。设置页同样可用。
- **R-SEARCH-3** 使用真实 `GET /api/v1/books?q=...&limit=5&offset=0` 预览；按当前 API 支持的书名、作者/译者、ISBN 搜索，不承诺未支持的标签全文。输入防抖 250ms；输入法组合结束后才触发；请求取消或序列校验，旧结果不覆盖新查询；空关键词关闭结果，不拉全库。
- **R-SEARCH-4** 下拉最多 5 本：小封面、书名、作者；缺封面用占位；底部"查看全部 N 个结果"（真实总数）。↑/↓ 选择，Enter 打开当前结果或全部结果，Esc 与点击外部关闭；浮层不被抽屉或顶栏裁切。
- **R-SEARCH-5** 点击结果进入真实详情；全部结果或直接回车进入书库并带 `q`。网络失败显示重试，不伪装成无匹配。

## 8. 页面

### 8.1 通用页面规则

- **R-PAGE-1** 页面容器分两档，均 `width: 100%` 且靠左：**列表型**（首页、书库）最大宽 1440px；**表单型**（设置、位置、存储）最大宽 960px。详情页最大宽 1440px，简介另按 R-DETAIL-5 限宽；登录最大宽 400px 并居中。尺寸在共享页面容器集中定义，页面不各自新增数值；超过最大宽时留白位于右侧。
- **R-PAGE-2** **所有页面的标题和内容统一靠左对齐**，容器不使用 `mx-auto` 居中；窄档页面靠左，右侧留白。登录和初始化页的居中面板不受此条约束；详情头部在内容宽 < 640px 时是另一明确例外：封面、书名和身份信息居中，简介及下方内容仍靠左。
- **R-PAGE-3** 页面结构：`PageHeader（标题 + 计数/说明 + 最多一个 soft 主操作）→ 工具栏 → 当前筛选 → 内容 → 分页（按需）`。
- **R-PAGE-4** 标题旁的说明只写与当前页相关的信息（如数量），不重复写产品概念。
- **R-PAGE-5** 未实现的功能不展示可点击的假入口；已开放的页面有加载、空、错误、重试和必要的禁用状态。

### 8.2 登录与初始化

- **R-AUTH-1** 居中单面板（最宽 400px）：框架背景 → acbooks logo → 标题/说明 → 表单 → 错误提示 → 全宽 `soft` 主按钮；窄屏允许纵向滚动；不用侧栏、装饰大图或营销内容。
- **R-AUTH-2** 初始化：用户名、密码、确认密码、一次性初始化码 → "初始化"；说明初始化码从受信任的宿主机取得，不通过页面自动获取。登录：用户名、密码 → "登录"；密码可见切换、回车提交、加载防重复；失败统一提示，不区分账号是否存在。
- **R-AUTH-3** 启动时查询真实初始化与认证状态；加载时不闪现书库；失败显示重试，不误入初始化页。
- **R-AUTH-4** 未认证时可直接切换语言（跟随系统/简体中文/English），并保留当前页面和输入；未认证仍不显示私人书库。
- **R-AUTH-5** 初始化成功后跳转登录，不视为已登录；已初始化时不显示创建账号入口；无公开注册、默认账号或在线密码恢复。Cookie/CSRF、来源校验、限流、凭据存储遵循 `security.md` 与 `api/conventions.md`；429 且带 `Retry-After` 时显示等待时间。
- **R-AUTH-6** 退出或会话失效后返回登录并清理私人页面状态。401 进入登录；403、网络和服务端错误按实际语义处理，不当成登出。

### 8.3 首页

- **R-HOME-1** 现有内容：最近添加（`sort=createdAt&order=desc`，复用 `BookCard`）+ "查看全部"。
- **R-HOME-2** **横向滚动列表必须可发现**：优先改成自适应网格（固定行数）；若保持横向滚动，加左右箭头和边缘渐隐。
- **R-HOME-3** **建议**增加"全部 / 实体书 / 电子书"快捷入口（带数量），链接到书库对应筛选。
- **R-HOME-4** 后续区块顺序：`继续阅读 → 最近阅读 → 藏书概览 → 最近添加`。继续阅读卡片：桌面封面/信息/操作三段，窄屏纵向或紧凑双段；进度、位置、目标必须来自真实阅读数据；无可继续文件时提供书籍详情入口。概览用轻量数字（藏书数、正在阅读、累计时长）；只展示真实可计算的指标，不伪造。
- **R-HOME-5** 无书时用 `EmptyState` 提供添加入口；运行监控、任务和日志不放首页。

### 8.4 书库

顺序：`PageHeader（书库 + 数量 + 添加书籍）→ 类型分段（全部书籍/实体书/电子书）+ 状态/排序下拉 + 筛选/视图/更多 → 当前筛选行 → 高级筛选面板（内联）→ 书籍网格或列表 → 分页`。

- **R-LIB-1** 书库是**统一的 Book 列表**，不拆成实体书库和电子书库；网格与列表复用相同数据与查询。
- **R-LIB-2** **视图**：网格/列表用两个图标的分段控件直接显示在工具栏，当前项高亮并持久化。封面大小（小/中/大 = 110/140/180px）仅在网格模式出现，放在旁边的小菜单里，与视图模式分开；列表模式隐藏尺寸入口并保留上次尺寸，切回网格后恢复。
- **R-LIB-3** **当前筛选行**：搜索词、状态、类型、高级条件的标签并排放在工具栏下方一行，每个都可单独移除，行尾"清除全部"（清除搜索只移除 `q`，保留其他条件）。没有任何筛选时整行不显示。搜索词**不放在标题旁**。
- **R-LIB-4** ⋯ 菜单只放低频操作（如刷新）；"清除全部筛选"在当前筛选行里。
- **R-LIB-5** 高级组合筛选保持现有交互：位于工具栏下方**内联展开**（不用抽屉或弹窗），字段、运算符、值编辑器、添加/删除/清空、固定底部操作和业务校验全部保留；视觉上紧凑。可清空。
- **R-LIB-6** 状态/排序/筛选/视图/分页写入 URL；修改筛选后回第一页；取消过期请求；服务端数据是唯一事实来源，分页和排序稳定。
- **R-LIB-7** **选择模式**（"选择"进入）：卡片/列表显示复选框；批量操作条原位显示已选数量、全选本页、清除选择、批量修改（阅读状态、标签/书架添加或移除）、删除；条**吸顶**且不遮挡内容；明确选择范围，不默认把本页选择扩展到全库；筛选、排序、分页或查询变化时清空选择。
- **R-LIB-8** 删除入口用 `danger`；确认框用 `danger-confirm`，说明会删除的关联数据（标签、书架、实体副本、文件索引、阅读会话、书签、笔记）以及 NAS 原文件保留策略。
- **R-LIB-9** 空状态区分三类：首次空库（添加入口）、无搜索结果（清除筛选）、加载失败（重试）。
- **R-LIB-10** 书籍主入口进入详情；低频操作放菜单；点击进入详情前保存列表上下文（见 11 节）。
- **R-LIB-11** 书架页展示已有书架与书籍数量，进入后复用统一书库结构；标签、书架与实体/电子筛选不复制 Book，不建第二套书库组件（待真实书架 API）。
- **R-LIB-12** 网格在容器内自适应列数，110/140/180px 是首选封面宽度；窄屏允许在同一档内适度收缩以填充可用列宽，不横向溢出。大封面可用单列，不强行缩成小封面；需验证 320px、390px 与文字缩放时的长书名和控件换行。

### 8.5 书籍卡片与封面

- **R-CARD-1** 网格卡片：封面（2:3、圆角 8）+ 书名（13px，最多两行）+ 作者（12px，一行）；无底板、边框、阴影；网格间距 16（窄屏 12）；列数自动计算。
- **R-CARD-2** 卡片**默认不加**格式角标和进度条。仅在确有需要时再加（如用户反馈分不清实体书和电子书）；加时必须小而克制：封面右下角一个角标区分"仅电子 / 仅实体 / 两者都有"（图标 + 本地化可访问名称）；进度条仅在有真实进度数据时显示，不伪造。
- **R-CARD-3** 列表行：目标行高 56，小封面 32，细分割线；显示格式、实体副本数、阅读状态；窄屏隐藏次要列，书名与关键操作始终可见。
- **R-COVER-1** 占位封面标题用 `break-words`，**不用** `break-all`，英文不在单词中间断开。
- **R-COVER-2** 小尺寸占位封面只显示书名，不显示作者；文字不小于 11px。
- **R-COVER-3** 真实封面图加 1px 淡色描边（用令牌，如 `ring-1 ring-inset ring-foreground/10`），避免白边封面在白底上"消失"。
- **R-COVER-4** 无封面时用确定性占位（书名 + 作者，对比度合格）；不联网获取；不因缺封面推断无电子书；无作者不生成虚构作者。封面上传限 PNG/JPEG/WebP、5 MB；上传中禁用并显示错误，成功后立即刷新，失败保留原占位。

### 8.6 书籍详情

路径 `/library/books/:bookId`。结构：`返回 → 书籍头部（封面 + 身份 + 操作区 + 简介）→ 内容区`。

**响应式**（以内容容器实际宽度 W 为准，优先 Container Queries，方向仅作测试场景；调整窗口、收起侧栏、旋转时自然重排，不卸载表单、不丢状态；不为横竖屏做两个页面实例）：

| 内容宽度 W | 布局 | 封面 | 操作区 |
| --- | --- | --- | --- |
| ≥ 1000px | 三栏 `150px / 1fr / 230px`，栏间距 24 | 150×225 | 纵向排列，顶对齐 |
| 640–999px | 两栏 `132–150px / 1fr` | 132–150 宽，2:3 | 信息下方横排，放不下换行；不留空第三列 |
| < 640px | 单列、居中 | 132×198（极窄可 112×168） | 主按钮全宽 44 高；状态与更多同一行；简介在操作区之后 |

- **R-DETAIL-1** **信息区字段顺序**：书名（页面唯一 h1；桌面 28–32、移动 24–28；桌面最多 2 行、竖屏 3 行）→ 作者 → 译者（独立，不混入作者）→ ISBN（可选，真实值）→ 标签/书架 → 简介。无值的字段不留空行。
- **R-DETAIL-2** 可点击规则：作者可按 `q` 跳转（说明不是精确作者筛选）；标签可按 `tag` 筛选；书架只有拿到真实 `shelfId` 或名称筛选接口后才可跳转，否则只显示名称。**不构造虚假的筛选链接**。
- **R-DETAIL-3** **操作区**：
  - 主操作：有阅读器后是"阅读"（`soft`，`size=lg`），"编辑"降为 `outline`；阅读器上线前"编辑"是 `soft`。有可读资源但无阅读入口时不显示无效阅读按钮；不从状态猜测百分比，不选第一个文件假装恢复位置。
  - 阅读状态：三段分段控件（未读/在读/已读），只提交变更字段，保存中禁用重复操作，失败保留原值并提示。
  - ⋯ 菜单**永远存在**，内含"删除"（`danger`，放底部）等低频操作；菜单支持键盘、Esc、点击外部关闭、焦点返回。
  - 复制 ISBN 是 ISBN 文字旁的小图标按钮（`Copy`），复制后显示"已复制"。
  - 封面上传/更换/删除放在封面区的菜单或覆盖层中，不常驻大按钮。
- **R-DETAIL-4** 删除不得作为与主操作等大的常驻按钮；删除书目、删除副本、移除文件分别确认，写清后果。整书菜单不能作用于单个文件。
- **R-DETAIL-5** **简介**：
  1. 只用 `BookDetail.description`，保留段落换行，去首尾空白，纯文本安全渲染，**禁止**未清理的 `dangerouslySetInnerHTML`；
  2. 默认最多 3 行（`line-clamp-3`），行高 1.65–1.75，`muted-foreground`；桌面最大阅读宽度约 65–75 个拉丁字符（`max-width`）；
  3. **真实发生截断时才显示**"展开简介"：测量折叠态溢出，监听容器尺寸、文本变化、字体加载；禁止按字符数猜测；
  4. 展开后按钮变"收起简介"；展开状态按 `bookId` 保存，切换内容、旋转屏幕、刷新详情不重置，切换新书默认折叠；
  5. 轻量文本/ghost 按钮 + `ChevronDown/ChevronUp`，`aria-expanded`、`aria-controls`；展开不开 Dialog、不移动焦点，保持触发按钮附近的阅读位置；
  6. 无简介：简短"暂无简介"或隐藏，不留大块占位，不把未加载当无简介；
  7. 保存编辑后用服务端返回的文本并重新判断溢出；快速切换书籍时旧请求不覆盖当前简介。
- **R-DETAIL-6** **体现多形态**：头部显示格式与实体副本摘要（如"EPUB · PDF · 实体 ×2"）。一本书可有多个副本和多个文件；存在多个可读文件时明确选择目标；不把文件级进度当成书籍唯一进度；文件缺失时保留书籍和阅读数据。
- **R-DETAIL-7** **未实现的标签不显示**。当前只有"信息"可用时直接渲染内容，不显示标签栏；阅读、笔记上线时再恢复标签（信息 / 阅读 / 高亮与笔记）。切换标签只换下方内容，不换头部。
- **R-DETAIL-8** **信息内容**：
  - 实体副本：数量、存放位置（空则"未设置"，不猜测）、取得时间（有值）、备注（有值）；有编辑/删除入口时用 IconButton；无副本显示"暂无实体副本"。
  - 电子文件：格式、大小、存在/缺失状态；不展示内部路径，不生成假文件名；缺失不自动删除书目或阅读历史；无文件显示"暂无电子文件"。
  - 补充信息：标识符、创建/更新时间（按 locale 与时区格式化）；不重复顶部已展示的字段。
  - 桌面空间足够时副本与文件并排，否则纵向；用分组标题、列表和细分隔线，不要求每行套卡片。
- **R-DETAIL-9** **阅读 / 笔记（后续）**：阅读展示文件独立进度、阅读指标、日期分组的会话时间线；笔记展示书签、划线、笔记，保留所属文件与定位。不把未接入的页面描述为"已有 0 条记录"，不把虚构进度条放进头部或文件行。
- **R-DETAIL-10** **编辑弹窗**：复用添加书籍的 `BookForm`（编辑与添加仅初值和提交接口不同）。桌面居中 Dialog，复杂表单最大宽 640，Header/Body/Footer 三段；桌面双列、窄屏单列，标题、简介和多值字段按空间跨列；低高度横屏时整体不超出视口，保存与取消始终可见。字段：书名（必填）、作者、译者（多值）、ISBN、阅读状态、标签、书架（多值）、简介。作者/译者/标签/书架用 `MultiValueInput`，简介用 `Textarea`，阅读状态用 `Select`。底部取消 `ghost` / 保存 `default`。提交遵循 BookUpdate 契约：未修改字段不提交；清空简介、ISBN 用 `null`；清空作者/译者/标签/书架用空数组；其他字段禁止传 `null`；空 PATCH 不提交；列表整体替换，不误删未编辑项。失败保留输入并显示本地化错误；写入需 CSRF。
- **R-DETAIL-11** 详情页数据边界：只展示接口真实字段，字段以 `docs/api/books.md` 与生成的 `schema.d.ts` 为准；不另造 DTO；详情 URL 直接访问、刷新、返回书库都正常；401 回登录，403/404/网络错误分别处理，不一律显示"无书"。

### 8.7 设置

- **R-SET-1** 设置采用**两级结构，桌面和移动一致**：
  - **设置首页**（`/settings`）：只显示各设置项的入口列表（图标 + 名称 + 一句话说明；当前为账户、外观、语言），不直接展开具体设置；
  - **具体设置页**（`/settings?section=...`）：点击入口后进入，只显示该分类，顶部有"返回设置"链接。
- **R-SET-2** 入口列表项整行可点击，用 `rounded-card` + `border`，有悬停和焦点状态；桌面端限制在表单型容器宽度内。**不再**同时显示分类标签栏和全部分组。
- **R-SET-3** 具体设置页用 `SettingsGroup` + `SettingsRow`：标题、可选说明、尾部控件；同组共享边界、行间细分割线；窄屏纵向重排；表单不铺满超宽屏。
- **R-SET-4** 主题和语言用分段控件（主题选项配 `Sun` / `Moon` / `Monitor` 图标且保留文字）；即时生效、本地持久化，独立于主题与时区，复用现有偏好状态与持久化键，不为同一偏好另建重复键或新增 API。
- **R-SET-5** 即时生效的布尔设置用开关；需要提交的用表单加 `default` 保存按钮；失败明确反馈并恢复或保留可重试状态；危险操作需真实契约与确认。
- **R-SET-6** 目标分类（按真实后端能力逐步开放）：

| 分组 | 分类 | 内容 |
| --- | --- | --- |
| 个人设置 | 账户、外观、语言 | 当前账号、退出、主题、界面语言；账号修改待接口 |
| 书库与存储 | 存储、元数据来源 | 管理/外部存储、扫描配置 |
| 数据与连接 | 备份与恢复、设备与同步、协议与集成 | OPDS/WebDAV 等 |
| 系统 | 任务与日志、关于 | 任务、健康检查、版本、许可证、项目链接 |

  acbooks 是单用户服务，不复制多用户权限、邮件、Kindle 等菜单。入口数量增多时再引入左侧分类栏。
- **R-SET-7** 外观设置：跟随系统/浅色/深色；唯一内置淡蓝；自定义配色含实时预览和恢复默认；预览使用同一套令牌与组件；不提供其他预设或玻璃设置。阅读设置（阅读器独立主题与偏好）后续开放。
- **R-SET-8** 返回入口必须验证为应用内允许的业务路径；刷新、前进、返回保持正确选中。

### 8.8 存储、位置与任务

- **R-STORE-1** 存储页：存储根列表（名称、模式、连接/可用状态）→ 添加/管理 → 上传/扫描入口；区分 managed 与 external，只展示获授权的操作。**`external` 始终只读**。
- **R-STORE-2** 任务状态严格使用后端 `queued / running / succeeded / failed`；`202` 只表示受理，未提供进度时显示不确定状态，**不伪造百分比**；轮询按需停止，离开页面不等于取消后台任务；失败显示必要错误摘要与可用的重试入口。
- **R-STORE-3** NAS 失联、文件缺失、无权限分别提示；只呈现 API 允许公开的信息，不暴露内部路径、堆栈、凭据；危险文件操作用确认对话框并说明后果。不自动合并歧义书籍。
- **R-STORE-4** 存放位置页：树形列表（按缩进展示层级）、每行显示名称与副本数，行内操作"查看书籍"和图标按钮（添加子位置、编辑、删除）；有子节点的位置不可删除。

### 8.9 阅读记录、统计与阅读器（后续）

- **R-READ-1** 阅读记录：PageHeader → 可用筛选 → 日期分组的会话列表 → 分页；会话行显示起止、有效时长、来源（手动/自动，用文字标识）、文件。统计与日历、书籍详情复用同一会话行和日期控件。
- **R-READ-2** 统计：PageHeader → 中性分段控件（周/月/全部，按接口支持）→ 周期导航 → 核心数字 → 趋势图 → 阅读日历 → 会话时间线。以 `reading_sessions` 为唯一事实来源，不在 UI 另算口径或重复累加重叠时间；时间按指定 IANA 时区显示；无数据不显示误导性趋势。图表只用主题强调色和必要状态色，保留单位、刻度、图例、文本摘要。
- **R-READ-3** 阅读器：独立沉浸页面，返回/书名 → 正文 → 按需出现的目录、进度、书签、设置；默认隐藏不必要的控件，保留键盘、触控和退出路径；阅读器配色、字体、行距独立于书库；不用玻璃或模糊；阅读位置与 `BookFile` 保存，记录有效会话；同步、离线和冲突遵循既有规范。

## 9. 国际化

- **R-I18N-1** 必须支持简体中文 `zh-CN` 与英文 `en`。默认跟随系统/浏览器（`zh-*` 到 `zh-CN`，`en-*` 到 `en`，无匹配回退英语）；用户可选跟随系统/简体中文/English；显式选择优先，独立于主题与时区，本地持久化、即时生效，无需刷新、登录或后端配置。
- **R-I18N-2** Web/Windows 共用一个 i18n 实例（i18next + react-i18next）；共享组件词条在 `packages/acbooks-ui/`，业务词条在对应应用，按功能组织，不重复维护公共词条。Android 用原生字符串与复数资源。
- **R-I18N-3** 所有用户可见文字（含提示、错误、状态、无障碍名称、标题、日期控件、图表、空状态）用稳定语义 key；**禁止**硬编码中英文、拼接翻译句子或只提供单语。新增或修改 key 时两种语言同步；用完整句模板、参数插值和复数规则。
- **R-I18N-4** 品牌名 acbooks、用户内容、书名、作者、文件名、原文、ISBN、技术标识不自动翻译。
- **R-I18N-5** 根节点 `lang` 随语言更新；日期、数字、百分比、时长用 `Intl`；时间戳、IANA 时区、纯日期和统计口径保持原规范；切换语言不改变业务值。
- **R-I18N-6** 中文输入法组合期间不提前提交或触发搜索。
- **R-I18N-7** API 错误按稳定 `code` 映射本地化提示；未知错误用通用译文并可展示请求 ID，不依赖后端英文 `detail`，不暴露敏感诊断。
- **R-I18N-8** 中英文共用同一布局与组件；允许长英文换行、控件增宽或重排，保留触控尺寸和操作语义；**不用**缩小字号、裁切关键文案或为两种语言建不同页面解决溢出。切换语言不得丢失路由、筛选、分页、选择、表单输入或登录状态。

## 10. 无障碍

- **R-A11Y-1** 弹窗、菜单、抽屉支持键盘、焦点管理，关闭后焦点恢复。
- **R-A11Y-2** 纯图标按钮有当前语言的可访问名称；状态不只靠颜色；图文按钮不重复朗读。
- **R-A11Y-3** 隐藏滚动条时必须保留滚轮、触控和键盘滚动；横向滚动区域要有可见的操作提示（箭头或渐隐）。
- **R-A11Y-4** 键盘焦点始终可见；移动触控目标 ≥ 44×44；桌面满足 WCAG 2.2 AA；支持文字缩放（200% 缩放下允许重排，不横向溢出）。
- **R-A11Y-5** 卡片和列表项的主入口用真正的链接或可访问的路由入口，不用只响应鼠标的 `div`。

## 11. 路由、数据与状态

- **R-DATA-1** UI 的认证、CSRF、会话、限流、错误码、分页和文件操作遵循 [安全规范](../architecture/security.md)、[API 约定](../api/conventions.md)。按真实 OpenAPI 接入，未实现的接口不得用假成功代替；复用生成的 API 客户端，不手改。
- **R-DATA-2** 会话检查、CSRF、退出和统一失效处理放在已登录框架或共享 AuthGate，业务页面不各自发起认证流程；不在 localStorage 保存密码、Cookie 或 CSRF Token；退出成功清理账户相关页面状态与请求。
- **R-ROUTE-1** 参考路由：`/home`、`/library`、`/library/books/:bookId`、`/locations`、`/storage`、`/settings`（及 `?section=`）；后续 `/shelves`、`/reading/history`、`/reading/statistics`。清单是目标，不代表全部存在。固定导航按真实路由激活；详情进入时书库来源高亮合理；未知路由显示安全的未找到页，不当成登录页。
- **R-ROUTE-2** 所有业务页都在认证保护下，直接打开和刷新都能正确加载。快速切换书籍、切换账号或离开页面时取消或忽略旧响应，避免串书。
- **R-ROUTE-3** 书库查询、筛选、排序、分页、视图写入 URL；进入详情前保存列表上下文（含滚动位置），返回后恢复；直接打开详情且无返回上下文时回到 `/library`。滚动恢复由 `layout/scroll-restoration.ts` 统一管理：新页面导航与分页回顶部，详情返回恢复位置，前进/后退按历史条目恢复。
- **R-ROUTE-4** 主题、语言、横竖屏、窗口缩放切换时保留分页、简介展开、编辑草稿和滚动上下文。

## 12. 工程与验收

- **R-ENG-1** `packages/acbooks-ui/` 放共享令牌、主题和可复用组件；`apps/acbooks-web/` 放页面和业务交互；Windows 复用 UI；业务规则留在后端。只按实际复用需要建目录。
- **R-ENG-2** 新组件需说明真实复用场景；新颜色/圆角/尺寸先核对本规范；不因某个页面调整全局组件；不引入新业务模型、接口或假成功响应。

### 12.1 实施顺序与迁移边界

- 本次文档迁移统一规则与阅读入口，不代表 UI 已完成升级；旧实现与目标差异应在实际改动时逐项验收。
- 建议顺序：公共控件与令牌 → 框架断点及导航 → 书库工具栏/当前筛选/批量操作 → 详情头部与编辑 → 设置与首页。每轮只交付一个明确目标；后续阅读功能等待真实 API 与阅读器。
- 规则编号是稳定引用：新增规则使用新编号，不为调整段落顺序重编号；明确例外应同时出现在通用规则和页面规则中。
- `book-detail-spec.md`、`management-layout-spec.md` 是旧链接的迁移指引，不能补充或覆盖本文；新增链接直接指向本文对应章节。
