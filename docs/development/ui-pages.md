# acbooks — UI 页面设计规范

> 修订：2026-11-12 · v3（中英文国际化 + Lucide 功能图标）
> 路径：`docs/development/ui-pages.md`
> 范围：Web / Windows；Android 仅参考信息层级和交互。
> 上位 UI 规范：[ui.md](./ui.md)、[ui-components.md](./ui-components.md)；工程约束：[standards.md](./standards.md)。本文仅规定页面结构、组件组合和交互；颜色、尺寸、圆角、动效、语言与图标策略以 `ui.md` 为准，业务与接口以现有架构、安全及 API 规范为准。冲突先报告，不另造规则。

## 1. 通用布局

- 已认证管理页面统一复用 `AppShell`：≥768px 为 80px 图标轨 + 56px 顶栏（全局搜索、账户入口），主内容在所有断点均为四周留 8px、浮于框架之上的圆角面板；<768px 为抽屉导航，支持从左侧边缘右滑打开、抽屉内左滑关闭。图标轨、顶栏与主内容之间不画分割线。初始化、登录、沉浸阅读不使用管理框架。
- 图标轨仅展示已实现的一级入口：首页、图书库；阅读、我的书架等在实现前隐藏，不摆放禁用占位。设置与账户由顶栏账户入口（头像 + 昵称）进入；移动端固定在抽屉底部；退出登录统一放在设置页账户分组，不再设独立的设置/退出按钮。实体书/电子书不是一级导航，统一为书库页内分段筛选。
- 每个页面以 `PageHeader` 开始：标题、可选计数/说明、最多一个 Soft 主操作。全局搜索固定在顶栏（移动端在抽屉内），书库页内不再放置重复搜索框；当前查询以可清除标签显示在计数旁。书库媒体分段与状态、排序控件位于标题下方，筛选、视图和更多操作组成右侧紧凑工具栏。
- 内容区按 `工具栏 → PageHeader（标题、数量、快捷筛选）→ 内容 → 分页（按需）` 排列；页面标题 22px，区块标题 16–18px，正文 14px，操作 13px，辅助 12px。每个操作区最多一个视觉主操作，不堆叠卡片，不使用玻璃或实心普通按钮。
- 操作层级：主操作（添加、导入、登录）使用带中性可读边框的 `soft`；表单提交/确认（保存、确认、应用）使用中性填充的 `default`；筛选、视图切换、次要导航等需要边界的操作使用 `outline`；取消、编辑和工具栏使用 `ghost`。不要让 `outline` 承担主操作，也不要在同一区域重复 `default`。
- 表单输入框始终保留可辨认边框；禁用态使用语义令牌保持尺寸、边框和可读文字，不通过整体透明度弱化。
- 保留有意义的搜索、筛选、排序、分页及视图状态；返回详情前的列表尽量恢复位置。窄屏重排内容、折叠次要操作，表格仅在自身区域必要时横向滚动。
- 任何页面区分加载、空结果、错误、权限/会话失效、成功；刷新优先保留已有内容并标明更新状态，不把未知数据当 0。未实现的功能不展示可点击的假入口。
- 全部页面按 `ui.md` 支持中英文，切换语言即时更新标题、导航、表单、错误、菜单、浮层、图表及日期等，不改变路由、筛选、分页、选择、表单输入或已登录状态；不自动翻译书籍内容及用户数据。
- 页面功能图标统一使用 Lucide，必须复用 `ui-components.md` 的语义映射与共享控件；展开导航、菜单采用图标 + 文字，折叠导航及紧凑工具栏可用纯图标 + 本地化名称/Tooltip。主要操作、危险确认和不明确操作保留文字；不为所有标题、字段或统计数字强行加图标。

### 页面功能图标（Lucide）

| 页面/区域 | 必要图标与用法（仅已实现功能） |
| --- | --- |

| 初始化 / 登录 | 使用现有 acbooks 品牌 Logo；语言切换 `Languages`、显示/隐藏密码 `Eye` / `EyeOff`；主按钮保留文字 |

| 书籍详情 / 编辑 | 返回、阅读、编辑、下载、更多、书架/高亮等按真实能力显示；编辑和删除目标清晰 |

| 设置 / 阅读器 | 语言、外观、账号、存储等分类图标；阅读器目录、书签、设置等沿用统一语义 |

## 2. 初始化与登录

共用 `AuthPanel` 页面布局（实际复用后再抽取）：框架背景 → 居中单面板 → acbooks 标志 → 标题/说明 → 表单 → 错误提示 → 全宽 Soft 主按钮。宽度、字段尺寸继承 `ui.md`；窄屏允许纵向滚动，不使用侧栏、装饰大图或额外营销内容。

| 页面 | 内容顺序与行为 |
| --- | --- |
| 启动状态 | 查询真实初始化状态及认证状态；加载时不闪现书库；失败显示重试，不误进入初始化页 |
| 初始化 | 用户名、密码、确认密码、一次性初始化码 → 「初始化」；说明初始化码从受信任的宿主机操作取得，不通过页面自动获取 |
| 登录 | 用户名、密码 → 「登录」；密码可见切换、回车提交、加载防重复；失败统一提示，不区分账号是否存在 |

- 初始化及登录页提供可直接访问的语言选择（跟随系统 / 简体中文 / English），无需登录；选择后保留当前页面和输入状态，未认证仍不得显示私人书库。
- 初始化成功跳转登录，不能视为登录成功；已初始化时不再显示创建账号入口。认证成功才进入书库；退出或会话失效后返回登录并清理私人页面状态。
- Web Cookie / CSRF、来源校验、限流、凭据存储遵循 `security.md` 与 `api/conventions.md`；按稳定错误码处理失败，429 且提供 `Retry-After` 时显示等待时间。无公开注册、默认账号或在线密码恢复入口。

## 3. 首页

顺序：`PageHeader → 继续阅读 → 最近阅读 → 藏书概览 → 最近添加 → 最近阅读记录`。

- 继续阅读：封面、书名、作者、可用的文件进度与最近时间、Soft「继续阅读」。无可继续文件时提供书籍详情或实体书记录入口，不伪造电子阅读进度。
- 最近阅读/最近添加复用 `BookCard` 网格，每区提供「查看全部」跳转真实筛选结果；不重复渲染同一本 Book。
- 概览优先使用轻量数字组（藏书数、正在阅读、累计有效时长等）；仅展示真实可计算的指标。无书时用 `EmptyState` 提供添加/导入入口，避免大量空统计卡片。

## 4. 统一书库与书架

`PageHeader(书库、总数、Soft 添加书籍) → 媒体分段(全部书籍/实体书/电子书) + 状态/排序 + 筛选/视图/更多 → 当前搜索标签 → 高级筛选(内联) → BookCard 网格或 DataTable → Pagination`。

- 全局搜索位于 56px 顶栏（移动端在抽屉内）；输入并确认后进入书库并携带 `q`。书库页内不再放置第二个搜索框，当前查询以可清除标签显示在计数旁，清除后保留高级筛选与其他查询条件。
- 书名、作者、ISBN 等已支持字段由全局搜索处理；实体/电子类型使用页内分段控件，阅读状态与排序使用紧凑下拉，网格/列表与封面尺寸统一放入视图菜单。高级组合筛选仍为页面内联展开的紧凑面板，保留字段、运算符、值编辑器、添加/删除/清空和固定底部操作；不改为抽屉或弹窗。可清空筛选。服务端分页与稳定排序遵循 API。
- 网格使用 `BookCard`：封面优先，小/中/大三档 110/140/180px，间距 16px（窄屏 12px），无卡片底板、边框或阴影；书名 13px 两行、作者 12px 一行。列表使用 `BookListItem`：目标行高 56px，小封面 32px，书名 13px、作者 12px，细分割线，保留必要元数据。两者共用查询、视图和封面尺寸状态，并持久化。书籍主入口进入详情；低频操作放入上下文/更多菜单。
- 批量模式原位显示已选数量、清除选择及实际支持的操作；明确当前选择范围，不默认将本页选择扩展到全库。筛选/分页变化时明确保留或清除的选择范围。
- 书架页展示已有书架与书籍数量；进入书架后复用统一书库结构。标签、书架与实体/电子筛选不复制 Book，不创建第二套书库组件。

## 5. 书籍详情与编辑

`Breadcrumb → 书籍头部 → Tabs(信息 / 阅读 / 高亮与笔记) → 当前内容`。桌面头部左封面右信息，窄屏纵向排列；头部展示书名、作者、阅读状态及实际可用的主要操作（阅读、编辑等），不使用封面背景模糊。

| 区域 | 内容顺序 |
| --- | --- |
| 信息 | 基本元数据 → 简介 → 标签/书架 → 实体副本（位置、购入信息）→ 电子文件（格式、大小、可用状态、操作） |
| 阅读 | 文件独立进度（如有）→ 阅读指标 → 分页阅读时间线；支持已实现的手动记录入口 |
| 高亮与笔记 | 书签、划线、笔记按真实数据展示，保留所属文件和可用定位信息 |
| 编辑 | Dialog 或独立表单：基本信息 → 分类/标签 → 其他已支持字段；使用 Field、Input、Select，底部取消 Ghost、保存 Default |

- 一本 Book 可有多个实体副本和多个电子文件；不能将文件级进度当成书籍唯一进度。存在多个可读文件时明确选择目标文件；文件缺失保留书籍和阅读数据。
- 编辑副本、电子文件与书目使用明确独立入口；不自动合并同名/同 ISBN/同哈希书籍。删除记录、移除文件或删除原件须明确目标与后果，按安全和存储规范分别确认。
- 阅读时间线复用统一会话列表：日期分组，显示起止时间、有效时长、来源和文件（适用时）；编辑/删除仅在接口支持时出现。修改日期复用公共日期控件，不创建另一套日历组件。

## 6. 阅读记录与统计

| 页面 | 内容顺序 |
| --- | --- |
| 阅读记录 | PageHeader → 日期/书籍等可用筛选 → 日期分组的会话列表 → 分页 |
| 阅读统计 | PageHeader → 中性 SegmentedControl（周/月/全部，按接口支持）→ 周期导航 → 核心数字 → 趋势图 → 阅读日历 → 会话时间线 |
| 阅读日历 | 月份导航 → 日历网格/热力图 → 所选日期的会话及总有效时长；宽屏可并排，窄屏纵排 |

- 统计优先展示累计有效时长、阅读次数、阅读天数、相邻阅读间隔等架构已定义且接口支持的指标；以 `reading_sessions` 为唯一事实来源，不在 UI 另算统计口径或重复累加重叠时间。
- 时间按现有 API 及指定 IANA 时区显示/分组；起止时间、有效时长与间隔明确区分。阅读来源（手动/自动）用文字标识；无数据不显示误导性趋势。
- 图表只用主题强调色和必要状态色，保留单位、刻度、图例及文本摘要；日期选择、周期切换与加载保持布局稳定，错误可重试。全局统计、书籍详情与日历复用会话行和日期控件。

## 7. 存储、导入与后台任务

| 页面 | 内容与交互 |
| --- | --- |
| 存储与导入 | 存储根列表（名称、模式、连接/可用状态）→ 管理或添加根目录 → 上传/扫描入口；区分 managed 与 external，只展示获授权的操作 |
| 导入流程 | 选择已允许来源 → 核对目标/候选（接口支持时）→ 提交 → 任务进度与结果；不自动合并歧义书籍，不承诺未完成导入 |
| 任务列表 | PageHeader → 状态筛选 → DataTable（类型、目标、状态、时间、必要错误摘要）→ 分页；任务详情显示实际结果与可用的重试入口 |

- 任务状态严格使用后端 `queued/running/succeeded/failed`；202 仅表示受理，未提供进度时显示不确定状态，不伪造百分比。轮询按需停止，离开页面不等于取消后台任务。
- NAS 失联、文件缺失、无权限分别提示；`external` 始终只读。只呈现 API 允许公开的信息，不暴露内部路径、堆栈、凭据；危险文件操作使用 AlertDialog。

## 8. 设置

`PageHeader(设置) → 设置分类导航 → SettingsGroup + SettingsRow`；宽屏可使用局部分类侧栏，窄屏使用分类列表进入子页；不改变全局 AppShell。

| 分类 | 内容（按已实现能力逐步开放） |
| --- | --- |
| 语言 | 跟随系统 / 简体中文 / English；即时切换并本地保存，独立于外观和时区 |
| 外观 | 跟随系统/浅色/深色；唯一内置淡蓝主题；自定义配色、实时预览、恢复默认；不提供其他预设或玻璃设置 |
| 阅读 | 阅读器独立主题及已实现的阅读偏好 |
| 账号与安全 | 修改密码、退出、设备及应用凭据管理；敏感凭据仅在 API 允许的时机显示 |
| 存储与数据 | 跳转存储/任务管理；备份状态及已实现的维护操作 |
| 关于 | 版本、开源许可证及项目链接 |

- 设置页使用页面内分类导航（宽屏）或分类列表（窄屏），不再依赖全局侧栏展示设置分类。设置组使用统一标题/简述、分割线、尾部对齐控件；即时布尔设置用 Switch，需要提交的配置用表单和 Default 保存按钮。失败明确反馈并恢复或保留可重试状态。
- 主题预览使用同一套令牌与组件；主题偏好可本地保存，不新增服务端接口作为前置条件，不保存认证凭据。

## 9. 阅读器（后续）

- 独立沉浸页面：返回/书名 → 正文 → 按需出现的目录、进度、书签、设置工具；默认隐藏不必要控件，保留键盘、触控和退出路径。
- 阅读器配色、字体、行距独立于书库；EPUB/PDF 等使用架构指定能力，功能按格式实际支持展示。不复用管理页面的固定正文字号，不使用玻璃或背景模糊。
- 阅读位置与 BookFile 保存，记录有效会话；同步、离线和冲突遵循既有规范，不在页面层另造计算/同步规则。

## 10. 实施与验收

- 本文是目标页面布局，不表示全部功能已存在。先查真实 OpenAPI、现有组件与任务范围；先完成初始化/登录与 AppShell，再按业务进度开发书库、详情、导入、统计及阅读器。
- 页面及业务交互放 `apps/acbooks-web/`；共享组件按实际复用放 `packages/acbooks-ui/`；Windows 复用 UI。测试与交付遵循 `standards.md` / `docs/testing/strategy.md`，不预建空页面、不复制 API DTO、不使用假成功响应。
- 验收：导航、工具栏、操作与反馈图标使用统一语义映射，品牌图标保持独立，折叠/纯图标控件有双语名称且可键盘操作；初始化/登录前及设置页均可切换语言；中英文完整、长英文不溢出、刷新保留语言、切换不丢失页面状态；默认淡蓝/深色、已实现的自定义配色、响应式、键盘焦点、状态反馈；Soft 主按钮边框/文字、Default/Outline 分工、分段选中边框、输入框边框和禁用态需通过浅深主题组件级对比度检查；重点验证初始化/登录跳转、书库筛选分页、详情文件归属、任务真实状态、统计时间口径及危险确认。未运行的检查不得声称通过。
